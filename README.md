# LabVIEW 通信程序设计 · 学习项目

针对**零基础**学习者制定的 LabVIEW 通信编程学习链路，配套知网参考书《LabVIEW通信程序设计》（人民邮电出版社）。

## 文件结构

```
LabVIEW_Comm/
├── README.md          # 本文件：项目概览
├── LEARNING_PLAN.md   # ⭐ 学习链路计划（7个阶段，约3周）
├── RESOURCES.md       # 配套资源清单
└── CHECKLIST.md       # 学习打卡清单
```

## 学习地图（速览）

```
环境基础 → 程序结构 → 数据/字符串 → 串口通信⭐ → 网络通信 → 仪器控制 → 实战项目
```

## 学习主线

1. **前3周节奏**：先跑通环境 → 吃透串口 → 最后做综合项目
2. **串口是重点**：学完即可对接你的 STM32 智能农业项目（AA55 协议帧）
3. **学练结合**：每个阶段都配动手小项目，不只看书
